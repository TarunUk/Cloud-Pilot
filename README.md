# CloudPilot

A modern, responsive frontend concept for **CloudPilot**, a fictional CloudOps platform designed to give developers a clear view of their applications, deployments, infrastructure, and monitoring.

The project focuses on creating a polished SaaS landing page with a premium Cloud/DevOps product experience.

## Features

* Modern CloudOps SaaS landing page
* Responsive design for desktop and mobile
* Interactive product/dashboard visualizations
* Deployment and infrastructure visual sections
* Monitoring UI with mock data
* Smooth animations and micro-interactions
* Dark premium visual design with layered gradients and visual depth
* Mobile layout optimized for 390px
* Desktop layout optimized for 1440px

## Tech Stack

* React
* TypeScript
* Vite
* CSS
* JavaScript
* Git & GitHub

## Project Scope

CloudPilot is a **frontend-only product concept** created for an assessment.

This project does not include:

* Backend
* Database
* Authentication
* Real cloud infrastructure
* Kubernetes integration
* AWS integration
* Real monitoring APIs
* Real deployment functionality

The dashboard uses static/mock data to demonstrate the product interface and user experience.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/TarunUk/Cloud-Pilot.git
cd Cloud-Pilot
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000/
```

### 4. Create a production build

```bash
npm run build
```

## Design Direction

CloudPilot combines modern Cloud/DevOps product UI with a premium SaaS landing-page aesthetic.

The visual direction takes inspiration from modern developer command centers and premium fintech interfaces while maintaining an original CloudPilot identity.

The design focuses on:

* Clear visual hierarchy
* Minimal information density
* Strong typography
* Layered interfaces
* Gradients and ambient backgrounds
* Responsive layouts
* Subtle animations and interactions

## Disclaimer

CloudPilot is a fictional product concept created for demonstration and assessment purposes. The dashboard information displayed in the project is mock data and does not represent real infrastructure or customers.
